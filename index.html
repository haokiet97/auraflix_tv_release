Cài bằng Downloader trên TV box

  1. Cài app Downloader (AFTVnews) từ CH Play trên box.
  2. Bật Settings → Enable unknown sources cho Downloader.
  3. Mở Downloader, nhập địa chỉ: is.gd/auraflixtv
  4. File tự tải về, bấm Install khi được hỏi.

Hoặc cài bằng ADB

  1. adb connect <IP-box>:5555
  2. adb install -r AuraFlixTV-1.1.0.apk

Nâng cấp từ bản cũ

  1. Mở Cài đặt → Cập nhật ứng dụng → Cập nhật ngay.
  2. Hoặc cài đè APK v1.1.0 — lịch sử xem, yêu thích và cài đặt được giữ nguyên.
