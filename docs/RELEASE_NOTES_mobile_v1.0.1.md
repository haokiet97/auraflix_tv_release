# AuraFlix Mobile v1.0.1 — Ghi chú phát hành

Bản vá cho trình phát trên điện thoại.

## Có gì mới

- Sửa lỗi **màn hình tự tối và khoá máy khi đang xem phim**.
- Trình phát giữ màn hình sáng ở cấp cửa sổ, ổn định cả khi tua, đổi tốc độ/tỉ lệ, chuyển tập hay đổi nguồn.
- Cờ giữ sáng được gỡ đúng lúc khi rời trình phát, không ảnh hưởng thời gian tắt màn hình của máy.

## Cài đặt

```bash
adb install -r AuraFlixMobile-1.0.1.apk
```

Hoặc copy APK vào điện thoại và mở (bật *Nguồn không xác định*). Bản mới được **cập nhật trực tiếp từ trong app**: Cài đặt → Cập nhật ứng dụng.
