# AuraFlix Mobile v1.0.2 — Ghi chú phát hành

Thêm thao tác vuốt nhanh trong trình phát.

## Có gì mới

- **Vuốt dọc nửa trái màn hình** để tăng/giảm **độ sáng** khi xem phim.
- **Vuốt dọc nửa phải màn hình** để tăng/giảm **âm lượng**.
- Hiện HUD với biểu tượng và phần trăm khi đang vuốt.
- Độ sáng chỉ áp dụng cho màn hình xem phim và tự khôi phục khi thoát.
- Tap hiện/ẩn điều khiển và double-tap tua ±10 giây vẫn hoạt động như trước.

## Cài đặt

```bash
adb install -r AuraFlixMobile-1.0.2.apk
```

Hoặc cập nhật ngay trong app: Cài đặt → Cập nhật ứng dụng.
