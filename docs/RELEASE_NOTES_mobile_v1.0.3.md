# AuraFlix Mobile v1.0.3 — Ghi chú phát hành

Thêm thao tác nhấn giữ để tua nhanh trong trình phát.

## Có gì mới

- **Nhấn giữ màn hình** khi xem phim: video tạm phát ở **2x**.
- **Nhả tay** thì quay về tốc độ đang chọn (1x, 1.25x, 1.5x…).
- Hiện nhãn `▶▶ 2x` ở phía trên trong lúc tua nhanh.
- Vẫn giữ nguyên các thao tác cũ: chạm hiện/ẩn điều khiển, double-tap tua ±10 giây,
  vuốt trái/phải điều chỉnh độ sáng và âm lượng.

## Cài đặt

```bash
adb install -r AuraFlixMobile-1.0.3.apk
```

Hoặc cập nhật ngay trong app: Cài đặt → Cập nhật ứng dụng.
